# eclose

> One-line description of the package.

## Installation

```sh
npm install eclose
```

## Usage

```ts
import {} from "eclose/react";
```

## Adapters

| Framework | Import path     | Status      |
| --------- | --------------- | ----------- |
| React     | `eclose/react`  | Available   |
| Vue       | `eclose/vue`    | Coming soon |
| Svelte    | `eclose/svelte` | Coming soon |

## Development

```sh
pnpm install
pnpm play   # playground at localhost:5173
pnpm test   # unit tests for the spring and geometry math
```

The playground drives the core engine directly from React, without the
components, so engine changes can be checked in a browser as they land.
