# Dialogs

<Lead>Content that grows from its trigger to the middle of the viewport.</Lead>

Set `placement="centered"`. It's modal by default.

## Card to detail

Put an `Eclose.Shared` with the same `id` on each side, and that element flies across on its own while the surface grows around it.

<Example name="card-to-detail" />

## Swipe to dismiss

On touch, pull down to dismiss. The list scrolls first, and only a pull from its top dismisses.
