# Styling

<Lead>The same parts, in any look.</Lead>

eclosion ships no CSS. Each part takes your own classes, and the motion draws real borders, radii and shadows all the way through. Here's one menu in five styles.

## Site

The look of this site. The trigger and the surface share one color, so they read as one shape.

<Example name="style-site" />

## Glass

A translucent fill with `backdrop-blur`. It needs something colorful behind it.

<Example name="style-glass" />

## Neobrutalist

Thick borders and a hard offset shadow. The shadow grows with the surface.

<Example name="style-brutalist" />

## Terminal

Monospace and sharp corners. Give `Eclosion.Close` children to replace its `×`.

<Example name="style-terminal" />

## Soft

Large radii and a wide, diffuse shadow. The radius morphs along with the size.

<Example name="style-soft" />

## Style by state

Every part has a `data-state` of `closed`, `opening`, `open` or `closing`.

```tsx
<Eclosion.Trigger className="data-[state=open]:pointer-events-none" />
```

## Good to know

- Don't put a CSS `transition` on `Eclosion.Content`. It fights the per-frame updates.
- Portals sit at `z-index: 9999`. Set `--eclosion-z` to change that.
